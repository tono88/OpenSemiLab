# Roadmap

## M0 — Foundation (current)

- Monorepo, CI, containers, scientific API contract.
- Responsive progressive interface.
- End-to-end PN-junction educational experiment.
- DEVSIM capability boundary and honest failure behavior.

## M1 — Validated PN junction

- Native DEVSIM worker.
- Poisson and drift-diffusion solve sequence.
- Mesh convergence study.
- Benchmarks against analytic limits and a published reference.
- JSON/CSV export and experiment comparison.

## M2 — Device laboratory

- MOS capacitor and MOSFET templates.
- 2D geometry and Gmsh integration.
- VTK field visualization.
- Local project history and reproducibility bundles.

## M3 — Multiphysics

- Electro-thermal experiment contract.
- MOOSE/FEniCSx worker spike.
- Joule heating example and cross-engine benchmark.

## M4 — Open EDA bridge

- Isolated IIC-OSIC-TOOLS workers.
- Connected RTL, formal, FPGA, ngspice/Xyce, openEMS, Xschem, CACE, GDS3D, and asynchronous LibreLane/OpenROAD execution.
- Downloadable GDSII, DEF, LEF, netlist, timing, metrics, and log artifacts.
- Next: normalized RF/characterization plots, board-specific FPGA bitstream packing, and exact GDS polygon rendering.
- PDK-aware course templates without redistributing PDK content.
