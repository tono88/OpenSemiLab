# Entradas del diseño

Documente función, interfaces, unidades y límites antes de escribir código.
Puede agregar RTL, VHDL, SPICE, esquemáticos o geometría. Mantenga módulos
sintetizables y estímulos en archivos separados con sus roles correspondientes.

La selección de lenguaje no traduce automáticamente Verilog a VHDL. Un módulo
o entidad no debe compartir nombre con otra implementación incluida a la vez.
